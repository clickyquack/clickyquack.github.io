# Political Will Map — site build

This folder is a small static site. **Write content in Markdown**; **run the build script** to regenerate the HTML pages GitHub Pages serves.

## Quick start

```powershell
cd political-will
pip install -r requirements.txt   # once
python build.py                     # after any content change
```

Then open `index.html` in a browser (or push and visit `https://clickyquack.github.io/political-will/`).

## What to edit vs. what not to edit

| Edit these | Do not hand-edit |
|---|---|
| `content/*.md` | `*.html` in this folder (generated by `build.py`) |
| `includes/*.html` (diagram snippets) | |
| `styles.css`, `assets/` | |
| `template.html` (shared header/nav/footer) | |

If you change a `.html` page directly, the next `python build.py` will overwrite it.

## Folder layout

```
political-will/
  build.py              # Markdown → HTML
  requirements.txt
  template.html         # Page shell (nav, header, footer)
  styles.css
  content/              # ← your writing lives here
    index.md
    about.md
    policy-work.md
    ...
  includes/
    mermaid-head.html   # Mermaid loader (injected when extra_head: mermaid)
    map-diagram.html    # Top-level clickable map
  assets/               # Images referenced from Markdown/HTML
```

## Editing an existing page

1. Open the matching file in `content/` (e.g. `content/policy-work.md`).
2. Edit the Markdown body.
3. Run `python build.py`.

Use normal Markdown: headings, lists, links, bold, nested bullets, etc.

### Raw HTML when Markdown is not enough

You can mix in HTML blocks where needed (the build uses the `extra` Markdown extension):

- Footnotes: `<sup><a href="#fn1">1</a></sup>` and `<p id="fn1">...</p>`
- Images with classes: `<img class="content-img" src="assets/foo.png" alt="...">`
- Short notes: `<p class="diagram-note">...</p>`

## Adding a new Markdown page

1. Create `content/your-page.md` with front matter and content:

```markdown
---
title: Your page title
output: your-page.html
parents: true
---

# Your page title

Your content here.

## Top external resources

- [Some link](https://example.com)
```

2. Run `python build.py` → writes `your-page.html`.

3. Add a nav link in `template.html` (copy an existing `<a href="...">` line in the `<nav>` block).

4. If the page should appear on the main map or in cross-links, update `content/index.md` and any other pages that should link to it.

### Front matter options

Put these between `---` lines at the top of each `content/*.md` file:

| Key | Example | Meaning |
|---|---|---|
| `title` | `Policy work` | Page `<h1>` topic; also used in `<title>` |
| `output` | `policy-work.html` | Output filename (default: `<filename>.html`) |
| `parents` | `true` | Adds “Parent pages: Main page” footer link |
| `body_class` | `map-page` | Optional CSS class on `<body>` |
| `extra_head` | `mermaid` | Loads Mermaid (required for diagram pages) |
| `full_title` | `true` | Use `title` as-is for `<title>` (no “— Political Will Map” suffix) |

## Mermaid diagrams

### Edit the main map

The top-level flowchart lives in **`includes/map-diagram.html`**, included from `content/index.md` via:

```markdown
<!-- include: map-diagram.html -->
```

`content/index.md` must have `extra_head: mermaid` in its front matter so the page loads the Mermaid script.

To edit the map:

1. Edit `includes/map-diagram.html` (the `flowchart BT` block inside `<pre class="mermaid">`).
2. Run `python build.py`.

**Tips for clickable nodes:** use HTML entities for angle brackets inside Mermaid labels, e.g. `&lt;a href='policy-work.html'&gt;Policy work&lt;/a&gt;`. Preview at [mermaid.live](https://mermaid.live) if helpful.

### Add a new Mermaid diagram on another page

1. Create a snippet in `includes/`, e.g. `includes/my-diagram.html`:

```html
<div class="diagram-wrap">
  <pre class="mermaid">
flowchart TD
  A[Start] --> B[End]
  </pre>
</div>
```

2. In your Markdown file, set front matter:

```markdown
---
title: My page
output: my-page.html
extra_head: mermaid
---
```

3. Include the snippet in the body:

```markdown
<!-- include: my-diagram.html -->
```

4. Run `python build.py`.

Any page with Mermaid needs **`extra_head: mermaid`** — that injects `includes/mermaid-head.html`, which loads and runs Mermaid on all `.mermaid` blocks on the page.

### Styling diagrams

- Map-specific layout: `styles.css` (`.diagram-wrap`, `.map-page`, etc.)
- Node colors in the main map: `classDef` lines in `includes/map-diagram.html`
- Global Mermaid theme: `includes/mermaid-head.html` (`themeVariables`)

## Images

Put files in `assets/` and reference them from Markdown:

```markdown
![Alt text](assets/my-image.png)
```

Or with a CSS class:

```html
<img class="content-img" src="assets/my-image.png" alt="Alt text">
```

## Troubleshooting

- **`ModuleNotFoundError: markdown`** → run `pip install -r requirements.txt`
- **Mermaid diagram shows as raw text** → page needs `extra_head: mermaid` in front matter
- **Mermaid syntax error** → check indentation inside `<pre class="mermaid">`; don’t add leading spaces to every line in the snippet file
- **Include not found** → `<!-- include: filename.html -->` must match a file in `includes/`
